# ai-strategy-toolkit

AI戦略実践プログラムの参加者向け配布物を置く公開リポジトリです。
各セッションで Colab から読み込むデータ・ノートブックをここから配布します。

ワークショップの中で「手元のAIに語らせた理想像」と「実データにコードとAPIで解かせた結果」を
突き合わせる体験に使います。データはすべて**合成データ**で、実在の個人・企業とは関係ありません。

## 収録セッション

| セッション | 題材 | 内容 |
|---|---|---|
| `s03-matching/` | 人材×求人のマッチング | 100名の人材プロフィールと60社の求人票（合成）を使い、制約の有無で結果がどう変わるかを体験する |

## ディレクトリ構成

```
s03-matching/
  data/              # 人材・求人データ（合成）
  precomputed/       # 事前計算結果（回線障害・APIキー未取得時のフォールバック用）
  notebooks/         # Colab で開くノートブック
```

## 使い方

各セッションの `notebooks/` にあるノートブックを Google Colab で開いてください。
ノートブックはデータを本リポジトリの GitHub raw から直接読み込みます。個別のダウンロードは不要です。

APIキーが未取得の場合や回線に問題がある場合でも、`precomputed/` の事前計算結果に自動でフォールバックして
一通りの流れを追えるようにしています。

## データについて

- 収録データはワークショップ用に生成した合成データであり、実在の人物・企業・求人ではありません。
- 数値・記述はいずれも架空のものです。実際の採用・転職の判断に用いないでください。
