# 小売（食品小売）　株式会社マチカド

セブン&アイ、イオン、ローソン、ファミリーマートなど食品小売大手数社を想定。

**会社と主人公**

コンビニ約2万店（9割超がフランチャイズ）を中核に、食品スーパー数百店を持つ食品小売グループ。専用工場と低価格PB、一日3便の物流網、数千万ダウンロードの自社アプリと決済基盤。主人公は**佐伯直人（52歳、取締役・営業本部担当）**。店舗スタッフ、SV、地区長と現場一筋で昇り、AI発注を全店に浸透させた張本人。生成AIは仕事で使うが「店に立ったことのない人間が語る未来」には身構える。大学生の娘は、何を食べるかまずスマホのAIに相談し、ネットスーパーの「お買い物AI」に献立とかごを作らせる。ただし決済ボタンは自分で押す。

**社風と空気**

単品管理と仮説検証の文化。「感覚で言うな、売上で言え」。本部は優秀で忙しく、SVは一人で10店を回りオーナーの愚痴も家庭の事情も聞く。国内店舗数は頭打ちで、成長は日販を上げるしかない。人手不足で24時間営業は当たり前でなくなり、SVの離職が増え、若手は「この仕事、あと10年あるのかな」と言う。ドラッグストアが食品で日販を伸ばし「1兆円企業」が続々生まれるのを横目で見ている。社食の会話：「うちは大丈夫でしょ、店があるんだから」「でも娘、何買うかまずAIに聞いてるよ」「で、どこで買ってるの」「結局うちの店。近いから」「ならいいじゃん」「いまはね」。

**現在地**

AI発注は2023年から全店導入、発注時間は4割減。AI値引き、欠品検知、揚げ物の需要予測が稼働。生成AI基盤を全社員に展開し、SVの経営分析や施策立案をAIが助言する。店内サイネージ1万店超とアプリの数千万IDを束ねたリテールメディアは広告会社と合弁を組み、モバイルオーダーと宅配は今春全国展開、2030年度に1,000億円規模を目指す。通信会社との実験店ではAIサイネージ、リモート接客、品出しロボットを試し、2030年度に店舗オペレーション3割削減を掲げる。次期中計の柱は、フレッシュフード強化で日販80万円、宅配、リテールメディア、加盟店契約の刷新（期間短縮とチャージ引き下げ）による出店再加速。すべて「今の店をもっと上手に回し、もっと稼ぐ」範囲で、深度でいえばD0〜D1。「顧客のAIが店を選ぶ」時代を前提にした項目は、まだ一行もない。

**止まる理由**

資産のすべてが「人が店に来る」前提で組まれている。加盟店契約も物流もリテールメディアも。加盟店1万人との関係は繊細で、契約刷新は50年で初めての大仕事だった。それを終えたばかりで「その先」を語る余力はない。そして「店を磨けば勝てる」ことを30年証明し続けてきた。成功体験が強いほど、店が要らなくなる未来は想像の外に置かれる。

**号令と解像度**

- **大久保清会長（74歳）**は年頭の全社集会で「AIで小売は根本から変わる。もう一度創業する気で」と言い、拍手のあと誰も何をすればいいのか分からなかった
- **高橋美咲・経営企画部長（41歳、コンサル出身）**は外資系コンサルの報告書を手に佐伯の部屋へ。「結論は『AIに推奨される店と、候補から脱落する店に分かれる』です。営業本部として何を柱に置けますか」
- **佐伯**「それで来期の予算に何を入れればいいのか、俺には分からない。オーナーに『AIが店を選ぶ時代です』と言って、彼らは明日から何をすればいい」
- **若手SV小林（29歳）**「AIに『今夜の夕飯、近くで安く』って聞くと、うちの惣菜は出てこないんです。隣のドラッグストアの冷凍食品は出てくる。誰に言えばいいのか」
- **加盟店オーナー田中さん（62歳）**「本部は未来の話ばかりだが、うちは今日の人繰りで精一杯だ。AIが店を選ぶって、じゃあうちの店は誰が選んでくれるんだ」

**社内に流れている未来像（真偽不明）**

- コンサル報告書：AIが消費者の代理人として探索・比較・購入まで代行する潮流が、検索・広告・モール前提の顧客接点設計を覆す。経済誌が今年6月に特集
- 懐疑派の根拠：海外の大手AI企業がチャット内決済を昨秋始め、今年3月に縮小。利用者はAIで比べるが、買うのは慣れた店。「AIは客を連れてくるだけで、売るのは店だ」と部長会は少し安心した
- 推進派の根拠：AI経由で来た客の購入率は検索経由より高く、昨年の年末商戦でAI経由の来訪は前年の9倍。AIと店をつなぐ共通規格が半年で三つ発表され、国内ECモール二社もアプリにAIエージェントを載せた。「入口を握られたら店は下請けになる」と高橋は言う
- 識者の講演（小林のメモ）：庫内在庫を認識する冷蔵庫を海外家電メーカーが今年の展示会で見せた。需要が事前に見えれば小売は「作って並べて売れ残る」から「決まった需要に届ける」商売に変わる。その時、店舗網は資産か負債か

**佐伯の問い**：2万店と1万人のオーナーと日々の商売を抱えたまま、この会社をどうやって「店が選ばれなくなるかもしれない未来」に備えさせるか。娘が今夜AIに相談した夕飯は、どこで買われるのだろう。

# 家電　株式会社クラシノ電機

パナソニック、シャープ、日立、三菱電機など家電大手数社を想定。

**会社と主人公**

白物家電と映像機器を中核とする家電事業会社。グループ全体ではB2B（電池・空調・産業機器・データセンター向け設備）の比重が高まり、家電はもはや稼ぎ頭ではない。主人公は**峰岸亮（57歳、常務・くらし家電事業本部長）**。冷蔵庫の設計者として入社し、商品企画、海外事業を経て家電の全商品を預かる。「いいモノを作れば売れる」を信じてきたが、量販店の棚で自社製品の隣に並ぶ中国ブランドの価格を見るたび、その信念が揺れる。妻は最近、家の照明とエアコンを海外製のスマートホームハブでまとめ、スマホのAIに「今日は寒いから帰る前に暖めて」と話しかけている。

**社風と空気**

技術者の誇りと、品質への執念。「壊れない、安全、静か」を守る文化は今も強い。一方で、シリコンバレー発で鳴り物入りだった暮らしの統合プラットフォームと家庭向けコンシェルジュサービスが昨年末から今年初めにかけて相次いで終了し、「家電からサービスへの転換」は社内で「二連敗」と呼ばれている。1万人規模の早期退職を経て、テレビ事業は「売却・撤退も含めて検討」の対象。若手の商品企画は「サービスの話を出すと『前回は…』で終わる」とこぼす。社内の会話：「またAIって言い出したよ」「今度は本気らしい、社外取締役にAIの先生が来た」「で、うちの洗濯機は何をしゃべるの」。

**現在地**

エアコンは在室パターンを学習し自動運転、オーブンや洗濯機は生成AIと連携してレシピや運転を提案し、下期には家電同士が連携して能動的に困りごとを解決する「エージェント家電」サービスを始める予定。グループは自社データで学習した1,000億パラメータの独自モデルを開発し、2035年度までにAI関連を売上の3割にする目標を掲げる。ただし家電事業の中計の柱は、高付加価値モデルへのシフト、コスト構造改革、B2B向け空調・設備の拡大。家電が「モノを売り切って終わり」であることは変わらず、深度でいえば製品はD1〜D2、事業モデルはD0。

**止まる理由**

収益は量販店経由の売り切りで立ち、量販店は自社PBを拡大し、中国勢は同機能を3割安で出す。家電はリサイクル法と長期の補修部品供給義務を負い、10年使われる。修理網と販売店網は資産であり固定費でもある。二連敗の記憶が「サービス転換」の議論を止める。そして、家をAIで束ねる主導権は、家電メーカーではなくスマホとAIプラットフォームの側にあることを、誰もが薄々分かっている。

**号令と解像度**

- **グループCEO・大沢**は「2035年にAI関連で売上3割」と言い、AI研究の第一人者を社外取締役に迎えた
- **家電事業CTOの九鬼（52歳、グループのAI技術センター所長から転任）**「家電の中で完結するAIでは勝てない。家全体のエージェントに、うちの家電をどう組み込ませるかだ」
- **峰岸**「組み込ませる、というのは、我々が部品メーカーになるという意味か」
- **若手商品企画の三上（31歳、統合PF事業の元メンバー）**「あの時は早すぎたんじゃなくて、家電を売るための仕組みだったから負けたんです。家電を売らなくても儲かる形にしないと」
- **量販店の商品部長**「御社のAI機能、店頭で説明できる販売員がいません。価格で並べるとC社が勝ちます」

**社内に流れている未来像（真偽不明）**

- 海外家電大手が今年の展示会で、生成AI搭載で庫内在庫を認識し賞味期限を管理する冷蔵庫を実物展示。「家のAI」を家電メーカーが握る道はまだ閉じていない、と九鬼は言う
- 懐疑派：スマートホームハブの新興が、どのメーカーの家電でも後付けでAI化できる製品を安価に売っている。「家電のAIは、ハブとスマホに吸われる」
- コンサルの試算メモ：消費者が家電をAIで比較して買う割合が上がると、ブランド指名率が落ち、価格と仕様の勝負になる。量販店経由の売り切りモデルは5年で粗利が3割減る
- グループ経営会議の議事録（漏れ聞こえた）：家電事業について「B2Bへの経営資源シフト」「事業会社化して自主責任」「必要なら資本の入替も」との文言

**峰岸の問い**：モノを売り切る家電事業を、家のAIに選ばれ、組み込まれる側にどう変えるか。二連敗のあとに三度目を提案する言葉はあるか。何もしなければ、5年後にうちの冷蔵庫は誰の指示で動いているのか。

# 金融（銀行・保険）　株式会社ナカバシ銀行

三菱UFJ、三井住友、みずほなどメガバンク、および日本生命、東京海上など大手保険を想定。

**会社と主人公**

国内三大金融グループの一つ。銀行を中核に証券・信託・カード・保険を持ち、個人口座は数千万。主人公は**芦田真理子（55歳、執行役員・リテール部門担当）**。支店長、本部の個人営業企画を経て、預金・ローン・投信・保険の個人向け事業を統括する。支店の統廃合と事務のデジタル化を10年進めてきた「効率化の人」。生成AIは毎日使い、部下より詳しい。息子はネット証券しか使わず、最近は家計簿アプリのAIに「来月いくら投資に回せる？」と聞いている。

**社風と空気**

「間違えない」文化。規制と監督指針、コンプライアンス、システム障害の記憶が、あらゆる意思決定を慎重にする。同時に、ここ2年で空気は明らかに変わった。三大グループ合計のAI投資は1,600億円規模、全行員に最新の生成AIが配られ、AIエージェントを数日で量産する仕組みが動き、頭取が自らエージェントを作った行もある。事務職5,000人分の業務をAIで削減する計画も出た。若手は「AIで一番速く変わる業界にいる」と言い、支店の中堅は「事務が減って、次に減るのは何だろう」と言う。社内の会話：「うちのAI、もう3,000体あるらしい」「客に見せてる？」「見せてない。全部社内向け」。

**現在地**

融資提案や制度融資の選定をAIエージェントが支援し、業務時間は4割減。面談記録、稟議、照会対応、コールセンターの一次対応にAIが入り、保険子会社は代理店システムとコンタクトセンターをAI前提で再設計中。中計の策定にもAIで競合分析を走らせた。次期中計の柱は「AIネイティブな組織」——業務の自動化、人員の再配置、データ基盤の統合、そして顧客向けAIチャットの高度化。深度でいえばD0〜D1を業界最速で走っている。だが「顧客が自分のAIに口座と資産を預け、そのAIが銀行を選ぶ」世界を前提にした項目は、中計にない。

**止まる理由**

金融は規制業であり、AIに判断させる領域は監督指針が線を引く。預金と決済は社会インフラで、止まることが許されない。巨大な勘定系と店舗網と人員は、効率化はできても組み替えるのに10年かかる。そして最大の理由は、この業界の収益が「顧客の惰性」に支えられていること。給与振込口座は変わらず、住宅ローンは借り換えられず、保険は見直されない。惰性が消える世界を、誰も本気で想像していない。

**号令と解像度**

- **頭取の榊原**「AIネイティブな銀行になる。投資額で他行に負けない」。実際に投資額は毎年更新される
- **デジタル戦略部長の池上（44歳）**「エージェントは社内では十分。次は顧客側です。お客さまのAIと話せる銀行にならないと」
- **芦田**「お客さまのAIと話す、というのは、お客さまのAIがうちより条件の良い銀行を毎月探してくる、という意味でもある。それで支店の何が残るの」
- **支店の融資担当・岡本（33歳）**「エージェントで稟議は速くなりました。でもお客さんは先月、ネットの家計AIに『この銀行のローンは割高』と言われて来なくなりました」
- **保険子会社の営業本部長**「営業職員3万人にAIを配った。だが顧客が自分のAIで保険を比べ始めたら、職員の価値はどこに残る」

**社内に流れている未来像（真偽不明）**

- 海外の大手AI企業が今年5月、チャットAIに銀行口座と証券口座を連携し、支出・投資・将来設計を相談できる機能を米国で公開。既に毎月2億人が家計や投資の相談にそのAIを使っているという。「入口を取られた」と池上は言う
- 国内では家計簿・資産管理アプリが数千万ユーザーを持ち、ネット証券がエージェント型のAIサポートを今月始めた。大手保険会社は海外AI企業と戦略提携し、AIエージェントを中核に業務基盤を作り直すと発表
- 懐疑派：「三行とも同じベンダーのAIを使っている。差がつくのは結局、金利と店とブランドだ」
- 識者の寄稿：顧客のAIが預金・ローン・保険を毎月最適化する世界では、金融機関の競争軸は「選ばれ続ける条件をAIに読める形で出せるか」に移り、選ばれない銀行は決済の配管になる

**芦田の問い**：業界最速でAIを入れながら、顧客の惰性が消える未来には備えていない。惰性なしで選ばれ続ける銀行とは何か。何もしなければ、5年後に息子の給与振込口座はどこにあるのか。

# B2B IT／コンサル　株式会社ハシラ情報

NTTデータ、日立、富士通、アクセンチュア、野村総合研究所など大手SI・コンサルを想定。

**会社と主人公**

金融・製造・公共向けのシステム構築と業務コンサルを手がける大手。売上の大半は受託開発と運用で、収益は「人数×月数×単価」で立つ。主人公は**黒田健一（54歳、執行役員・金融事業本部長）**。銀行の勘定系刷新を20年担当し、数百人のプロジェクトを何度も納めてきた。部下は2,000人、協力会社を含めれば5,000人が動く。生成AIでの開発支援は自ら試し、速さに驚きつつ「本番系を任せるのはまだ怖い」と言う。娘は転職先の小さなSaaS企業で、AIコーディングツールを使って一人で機能を出荷している。

**社風と空気**

納期と品質への責任感、顧客の業務への深い理解、そして多重下請けの構造。「稼働率」が最重要指標で、部長は毎月、人が余っていないか足りていないかを数える。この1年で空気は独特のねじれ方をしている。自社は顧客に「AIで業務を変革しましょう」と提案し、AI関連の受注は伸びている。社長は「人月モデルからの脱却」を公の場で語り、海外の同業は「リスキルできない人材は退出」と宣言して1万人を削減した。だが現場は空前の人手不足で、モダナイゼーション案件が3年先まで埋まっている。若手は「AIで3人でできる仕事を、30人で見積もる理由が分からない」と言い、中堅は「30人で見積もらないと、来期の売上がなくなる」と言う。

**現在地**

コーディング、テスト、ドキュメント生成に社内AIツールを標準装備し、工数は工程によって3〜5割減。自社パッケージ製品の改修はAI駆動開発に切り替え始めた。顧客向けにはAIエージェント導入、データ基盤、業務改革のコンサルを売り、AI人材を倍増する計画。中計の柱は、AI関連事業の拡大、成果報酬型・サブスク型契約の試行、人材ポートフォリオの転換。顧客にはD2〜D3の絵を描いて売っているが、自社の収益構造はD0の人月のまま。「人月をやめる」と10年言い続けて、まだやめられていない。

**止まる理由**

人月をやめると、AIで速く作るほど売上が減る。成果報酬型はリスクを自社が負うことになり、大規模基幹系では誰も取りたがらない。顧客の調達部門も「人月で買う」以外の稟議の書き方を知らない。協力会社網は人月で回っており、切り替えれば数千人の行き場が問題になる。そして皮肉なことに、目の前の需要が旺盛すぎて、事業モデルを変える余裕が今年もない。

**号令と解像度**

- **社長の時任**は経営ビジョンで「労働集約型SIから、価値・成果ベースへ。2035年までに開発工程をAIエージェントで自動化する」と宣言し、3年中計を廃止して10年ビジョンに切り替えた
- **黒田**「ビジョンは正しい。だが今期の受注残は全部人月契約だ。来期の売上をどう立てながら、モデルを変えるのか」
- **若手リーダーの西村（30歳）**「先週、顧客のCIOから『来年度から人月では発注しない。成果で出せ』と言われました。うちの見積システム、成果で書けません」
- **協力会社の社長**「御社がAIで内製したら、うちは何を納めればいいんですか」
